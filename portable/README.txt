TTSK Dim Plates - portable package

1. Install and activate Tekla Structures 2025 SP7.
2. Open Tekla Structures and the model/drawing that you want to process.
3. Double-click "TTSK Dim Plates.exe" (or "Start TTSK Dim Plates.bat").

The package contains the application and its NuGet dependencies. Tekla
Structures product DLLs are intentionally not included because they are
supplied by the Tekla installation and are subject to Trimble licensing.

If Tekla is installed outside the standard location, set the TeklaBinPath
environment variable to its "bin" folder before launching the application.
