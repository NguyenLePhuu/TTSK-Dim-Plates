TTSK Dim Plates - portable package

1. Install and activate Tekla Structures 2025 SP7.
2. Open Tekla Structures and the model/drawing that you want to process.
3. Double-click "TTSK Dim Plates.exe" (or "Start TTSK Dim Plates.bat").

The package contains the application and its NuGet dependencies. Tekla
Structures product DLLs are intentionally not included because they are
supplied by the Tekla installation and are subject to Trimble licensing.

If Tekla is installed outside the standard location, set the TeklaBinPath
environment variable to its "bin" folder before launching the application.

--- AUTO UPDATE & CONFIGURATION PRESERVATION ---
- Official Releases: Download "TTSK-Dim-Plates-Portable.zip" from GitHub Releases.
- Auto Update: When a new version is available, the version label in the app
  displays an indicator (e.g. "v1.0.0 ↑"). Click the label to view release notes
  and perform a one-click automatic update.
- User Configuration Preservation: Personal config files (theme.cfg, shortcut.cfg,
  auto_section.cfg) and logs are 100% preserved during updates and will never be
  overwritten or deleted.
- Bootstrap from older versions: Older portable packages without the updater
  require a one-time manual copy of the new runtime files into the existing folder
  (keeping your existing .cfg files intact). Future updates are fully automatic.
